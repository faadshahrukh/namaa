Overall Site Features (Applies to All Pages)

Navigation: Sticky top bar with logo, main menu (Home, Brokers, Calendar, News, Academy, Tools, Scam Alerts), search bar (global search across news/brokers/events), user account (login/register for personalized alerts, watchlists, forums).
Footer: Links to About, Privacy, Terms, Contact, Sitemap, social media, disclaimers.
Responsive Design: Mobile-first, dark/light mode, timezone selector.
Monetization/Engagement: Broker affiliate links (disclosed), premium subscriptions (ad-free, advanced tools), community forums, newsletters, push notifications.
Tech Stack Considerations: Real-time data feeds (e.g., for calendar/markets), user-generated content moderation, SEO for organic traffic.
Accessibility: High contrast, alt text, keyboard navigation.

1. Home Page
Purpose: Engaging landing page with quick value, market overview, and calls-to-action (CTAs) to other sections.
Key Sections:

Hero Banner: Live major pairs rates (EUR/USD, GBP/USD, etc.), market sentiment (e.g., "Bullish on USD today"), search bar, and prominent CTAs ("Explore Brokers", "Check Calendar", "Start Learning").
Market Snapshot: Real-time quotes, pip changes, charts for majors/minors (inspired by Forex Factory market data). Include trader positions aggregator (long/short % like Forex Factory).
Today's Highlights:
Upcoming high-impact events (mini calendar).
Latest news headlines (3-5 curated).
Top broker deals or verified picks.

Community Pulse: Recent forum threads, live trade feeds, or sentiment indicators.
Educational Teaser: "New to Forex? Start with our Academy" + featured lesson.
Scam Watch: Recent alerts or "Verified Safe Brokers" carousel.
Footer Teasers: Testimonials, stats (e.g., "10k+ traders online"), newsletter signup.

Goal: Reduce bounce rate; guide users to key actions within 10 seconds.
2. Brokers Page
Purpose: Comprehensive broker discovery, comparison, and regulation focus (core from WikiFX + Forex Factory).
Key Sections/Subpages:

Broker Search/Filter: By regulation (FCA, ASIC, etc.), account type, spreads, platforms (MT4/MT5, cTrader), features (Islamic, bonuses), user ratings.
Rankings/Lists: Top regulated brokers, best for beginners, ECN, etc. (scores based on regulation, reliability, user reviews).
Broker Profiles: Detailed pages with regulation verification, spreads comparison, pros/cons, user reviews/ratings, scam reports (if any), affiliate signup.
Comparison Tool: Side-by-side table for 3-5 brokers (spreads, leverage, deposits, etc.).
User Reviews & Exposure: Moderated reviews + integration with scam alerts.

CTAs: "Open Account" (affiliate), "Compare Now".
3. Calendar Page
Purpose: The industry's best economic calendar (inspired by Forex Factory + FXStreet).
Key Features:

Interactive Table: Date/time (user timezone), currency, event name, impact (high/medium/low color-coded), forecast/actual/previous, historical graphs.
Filters: By country, impact, keyword, date range, currency pair relevance.
Real-Time Updates: Live results, countdown timers, notifications (email/push for high-impact).
Additional Views: Weekly outlook, market impact analysis post-event, volatility forecasts.
Integration: Links to related news/analysis on the site.

Goal: Traders' daily go-to for event risk management.
4. News Page
Purpose: Aggregated, timely forex/market news (FXStreet + DailyFX + Forex Factory).
Key Sections:

Latest News Feed: Real-time headlines with categories (Forex, Commodities, Crypto, Geopolitics, Central Banks).
Analysis & Forecasts: In-depth articles, technical/fundamental breakdowns, daily/weekly outlooks.
Video/Newsroom: Embedded videos, webinars, live streams.
Personalization: User watchlist-based news (e.g., follow EUR pairs).
Archives/Search: Advanced filtering by date, topic, author.

Features: Comments/discussion, share buttons, "Related Events" linking to calendar.
5. Academy Page
Purpose: Structured learning (BabyPips-style, expanded with DailyFX resources).
Structure:

Courses: Modular "School of Pipsology" equivalent — Preschool (basics), Elementary, Intermediate, Advanced. Progress tracking for logged-in users.
Lessons: Text, videos, quizzes, infographics on topics like pips, leverage, risk management, strategies, psychology.
Resources: Glossary, eBooks, webinars archive, strategy simulators.
Community Learning: Forums tied to lessons, Q&A.
Levels: Beginner, Intermediate, Pro paths with certifications/badges.

Goal: Onboard new users and build loyalty through education.
6. Tools Page
Purpose: Practical trading utilities (FXBlue + Forex Factory + others).
Key Tools/Subpages:

Market Data: Live charts, scanners, heatmaps, correlation tools.
Trading Calculators: Position size, pip value, margin, profit/loss, Fibonacci.
Analysis Tools: Sentiment indicators, trade journal/template, backtesting/simulator.
Account Tools: Performance analytics (upload statements), trade copier signals (if applicable).
Other: Economic impact estimator, volatility tools, mobile app links.

Features: Embeddable widgets, API access for pros (future phase), favorites/watchlist.
7. Scam Alerts Page
Purpose: Build trust and user protection (WikiFX strength + community reports).
Key Sections:

Latest Alerts: Curated/verified scam reports, blacklisted brokers, common fraud types (e.g., fake signals, unregulated platforms).
Broker Verification Tool: Quick search for regulation status and risk score.
User Reports: Submit form (with evidence moderation), community-voted exposures.
Education on Scams: Guides on "How to Spot Scams", red flags, recovery resources.
Safe Trading Hub: Links to verified brokers, regulatory authorities database.

Features: Database searchable by broker name, real-time updates, success stories of resolved cases.

Phase 1 Launch Priorities:

Focus on core content population (calendar + news feeds first for SEO/traffic).
MVP: Functional pages with real-time elements via APIs/partnerships.
User onboarding: Simple registration for alerts and personalization.
Analytics: Track popular pages/tools to inform Phase 2 (e.g., forums, advanced charting, mobile app).
